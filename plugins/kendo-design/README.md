# Kendo Design System Plugin

The Kendo Design System — design tokens, typography, spacing, color system, elevation, and accessibility guardrails that guide AI agents to generate consistent, accessible UI for data-rich professional interfaces.

## Skills

| Skill | What it does |
|-------|-------------|
| `kendo-design` | Applies the Kendo Design System to UI work — design tokens, visual guidelines, spacing rhythm, and accessibility guardrails. Auto-loaded whenever you generate or review UI, or invoked explicitly as `/kendo-design [target]` |
| `kendo-themes` | Styling reference for Kendo and Telerik UI components — theme installation, CSS/SCSS token properties, theme customization, design tokens, swatches, Tailwind token mapping, and component selectors |

## Usage

### Apply the design system

```
/kendo-design Build a settings page with form inputs
```

### Ask about theming

```
How do I customize the primary color for the Material theme?
```
```
What CSS variables control spacing in Kendo themes?
```

Skills are triggered automatically from natural language. You can also invoke them explicitly with a slash command, e.g. `/kendo-design`.
