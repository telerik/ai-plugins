# Telerik UI for Blazor — Suite Identity & Themes

## Suite Constants

| Constant | Value |
|----------|-------|
| Suite name | `Telerik UI for Blazor` |
| NuGet package | `Telerik.UI.for.Blazor` |
| Available themes | `default`, `bootstrap`, `material`, `fluent` |

## Theme CSS Paths

| Theme | CSS Path (relative to `_content/Telerik.UI.for.Blazor/css/`) |
|-------|--------------------------------------------------------------|
| Default | `kendo-theme-default/all.css` |
| Bootstrap | `kendo-theme-bootstrap/all.css` |
| Material | `kendo-theme-material/all.css` |
| Fluent | `kendo-theme-fluent/all.css` |

## Theme Import Example

```html
<link rel="stylesheet" href="_content/Telerik.UI.for.Blazor/css/kendo-theme-default/all.css" />
```
