# Phase: Layout Responsive Finalization

Load and follow the **[kendo-angular-layout](../../kendo-angular-layout/SKILL.md)** skill. When calling `kendo_layout_assistant`, focus the prompt on responsive behavior across mobile, tablet, and desktop views.

**Tool call example:**
```
kendo_layout_assistant({
    prompt="Provide Kendo Design System utility classes to make the following layout structure responsive across mobile, tablet, and desktop views: [LAYOUT DESCRIPTION HERE]",
    includeBuildingBlockExamples=false
})
```
